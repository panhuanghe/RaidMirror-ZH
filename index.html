🖥️ 数据从不离开你的浏览器
客户端 ID 只存储在你本地浏览器的 localStorage 中，不会发送到任何服务器

WCL API 只能读取公开日志数据(和所有人在 WCL 网站上能看到的一样)，无法修改/删除/访问任何私密内容
🔍 开源

🚫 不是你的 WCL 登录
